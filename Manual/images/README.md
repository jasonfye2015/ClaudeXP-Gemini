# Screenshots for the manual

The pages refer to these pictures. Until a file is here, the viewer shows "Screenshot: ... (not taken yet)" in its
place. Take them with the real computers running normally (PNG, about 1400 px wide is plenty), save them under these
names, and the pages pick them up.
