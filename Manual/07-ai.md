# 7. The language models

Everything that talks in the Timeline - the buddies, the IRC and MUCK regulars, the residents' diaries and mail, the
written Web, ClaudeAI, Kithylin - is a language model running on your own graphics card, through llama.cpp. Nothing
goes online.

## The folder

`Local Storage\LLM Models\`:

- `models\<name>\` - one folder per model; the folder name is the model's name everywhere. Inside: the model's
  `.gguf`, an optional `mmproj-*.gguf` so it can see pictures, and an optional `info.json` (title, source, licence,
  notes, suggested jobs, chat template, stop words). **To add a model, add a folder.**
- `llama.cpp\vulkan\` - the engine (build b11533): `llama-server.exe` and its DLLs. Vulkan runs on NVIDIA, AMD and
  Intel cards, or the CPU.
- `llama.cpp\cuda\` - the CUDA 12.4 build, optional. (CUDA 13 dropped the GTX 10-series.)
- `llama.cpp\macos\` - the Apple silicon build, for the Mac.
- `llama.cpp\src-b11533\` - llama.cpp's source, for the converter that training uses.
- `image-gen\`, `voice\` - Stable Diffusion and the speech engines, installed by the Copilot programs.
- `selfmodel\` - [training](09-training.md).

## The models and their jobs

| Model | Size | Default job |
|---|---|---|
| **NemoMix Unleashed 12B** (MarinaraSpaghetti, a Mistral Nemo merge) | 7.5 GB | Buddy conversations: roleplay and stories, less filtered. Also the base the later Kithylins sit on |
| **Gemma 4 12B** (Google) | 7.2 GB + projector | ClaudeAI; thinks before answering; sees pictures |
| **Gemma 3 4B** (Google) | 2.5 GB + projector | Pictures: used when a message carries a picture the chosen model can't see. The base of the first Kithylin |
| **Gemma 3 1B** (Google) | 0.8 GB | Background life: journals, e-mail, ambient chatter |
| **Mag-Mell R1 12B** (inflatebot) | 7.5 GB | An alternative roleplay voice (no licence stated by its author) |
| **Qwen2.5 Coder 1.5B / 7B**, **Qwen3 4B Instruct** (Alibaba) | | Python Studio's AI Helper |

On a GTX 1080 Ti (Vulkan, 16K context, 8-bit cache): the 1B does about 125 tokens a second, the 4B about 75, the 12Bs
about 32. A 12B and the 1B fit on the card together (about 10.2 of 11 GB).

**Control Panel > AI Models** (on every computer; Settings has it too on the Windows 11 one) is where this is
managed:

- **Models** - what's installed, its size, whether it sees pictures or thinks, whether it's loaded; Load, Unload,
  Test, Properties.
- **Assignments** - which model does which job: buddy conversations, background life, ClaudeAI, pictures, Clippy
  (on XP), Python Studio. Plus a model of their own for any one resident.
- **Engine** - Vulkan or CUDA, the graphics device, how many models stay loaded (default 2), the context size,
  unloading when idle, Start / Stop / Restart / View Log.
- **Activity** - the request queue and recent replies, with tokens per second.
- **Setup** - the AI Model Setup Assistant, which downloads what's missing.

These choices are each computer's own (`data\ai_models.json`), so the XP machine and the Windows 11 machine can run
different models.

## How it runs

Each computer starts one `llama-server` router quietly on 127.0.0.1 at logon and stops it at shutdown. Models load
the first time something asks for them (the AI loading box), and the least recently used is unloaded when more are
needed than "models kept loaded" allows. Without the `LLM Models` folder everything still works except the talking,
and a warning sign says so.

## The graphics card: one heavy thing at a time

The card has 11 GB. On Windows the NVIDIA driver doesn't fail when video memory runs out: it quietly spills into
system RAM and everything runs about thirty times slower. So:

- **Training needs the card to itself.** Close the computers and Kithylin AI before starting a training run, and
  don't open them while it runs.
- Kithylin AI's own models start a `llama-server` of their own; inside a computer, a model from `Local Storage` goes
  through the computer's router instead so the card is shared properly.
- "CPU only" in Kithylin AI's Settings leaves the card alone entirely, slowly.
- Image Creator (Stable Diffusion) also wants the card. Don't run it alongside a 12B.

## The AI programs

- **ClaudeAI** - a Claude Desktop-style chat with the local model: pictures, thinking. It sits in the notification
  area while it runs (Load at Startup is on by default); closing the window tucks it back there, Exit quits.
- **Kithylin AI** - the model of you. [Its own chapter](08-kithylin.md).
- **CopilotAI** - a general chat assistant, by text or voice, with pictures from Image Creator.
- **Copilot Voice** - speech in and out: Whisper for listening, Piper for speaking, installed into
  `LLM Models\voice` by its own setup (needs the Internet once; runs locally after). CopilotAI uses it for
  push-to-talk and spoken replies.
- **Copilot Image Creator** - pictures from a description: Stable Diffusion 1.5 or SDXL, installed into
  `LLM Models\image-gen` by its own setup.
- **Copilot Python Studio** - write, check, debug and run Python offline, with an AI Helper. It has its own Python
  3.12 in `Local Storage\Python Studio`, about sixty offline wheels (numpy, Pillow, pygame, matplotlib, flask...),
  ffmpeg for the audio and video converter, offline manuals, and Build Executable. To add a package, put its `.whl`
  in `wheels\` and use Tools > Install Package from Offline Wheels.
- **Copilot Widgets**, **Copilot Neko** - a widgets panel, and the desktop cat.
- **Clippy** (XP only) - the Office Assistant, with tips written by the model.
