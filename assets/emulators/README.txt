fceumm_libretro.dll
-------------------
The NES emulation core used by ClaudeXP's NES Emulator (claudexp/programs/nes).

FCE Ultra mm (FCEUmm), libretro build for Windows x86_64, downloaded 2026-10-09 from
https://buildbot.libretro.com/nightly/windows/x86_64/latest/fceumm_libretro.dll.zip

FCEUmm is free software licensed under the GNU General Public License, version 2.
Source code: https://github.com/libretro/libretro-fceumm

ClaudeXP loads it as a separate library through the libretro API; no game ROMs are included.

snes9x_libretro.dll
-------------------
The Super NES emulation core used by ClaudeXP's SNES Emulator.

Snes9x 1.63, libretro build for Windows x86_64, downloaded 2026-10-09 from
https://buildbot.libretro.com/nightly/windows/x86_64/latest/snes9x_libretro.dll.zip

Snes9x is free for personal, non-commercial use under its own licence (see
https://github.com/snes9xgit/snes9x/blob/master/LICENSE). Source: https://github.com/libretro/snes9x
