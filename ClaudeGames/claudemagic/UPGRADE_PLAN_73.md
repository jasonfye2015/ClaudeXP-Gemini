# UPGRADE_PLAN_73 - Curiosities

Asked for: a very large update scattering easter eggs through the game - items, mechanics, monsters, text and more -
and kept secret from the person who asked for it. So this plan says how, and not what.

## How they're kept
- **Secret by design.** The release notes, the Help, the Manual and the commit messages say only that there are things
  to find. This file doesn't list them. The tests have plain names. (The source files do say what they are; they're
  69zzzw-curios.js, 69zzzx-curios2.js and 77g-curios.js, for anyone who would rather know.)
- **The ledger.** Each one found is written once in the village's ledger, never in a replay. Claude keeps a small box
  on his shelf with a slip in it for each: it says how many have been found, never what, and never how many there are.
- **Rules they keep.** All original. None breaks a save or a run, or touches the ladder, the boards or the
  achievements; a few kept things help a little. Every one can be found - some at once, some by the hour, the day,
  the seed or the name, and some only with real persistence.

## Where they are
Everywhere: the title card, the town, the Wood, every band of the dungeon, Claude's cabin and Claude himself, the
fights, and the walk between them.

## Order
Two releases: the first and the second half.
