This ZIP contains icons for the desktop.

There's a small message on the top left, that will need to be moved to the top right.

For Recycle Bin, it has two, "Full" which the system uses when any file is inside the recycle bin, and "Empty" when it's totally empty. When double clicked, it will open up the Recycle bin folder, with expected features of windows 7. When right clicked on it will expand a menu,  and will also have expected items in it.

under that, will be "Desktop", which is the desktop folder, inside will have "CD Rom Drive", "DVD Drive", "Floppy Drive", "External HD", Internal HD". it's drop down menu will have expected features of windows 7. When right clicked on it will expand a menu,  and will also have expected items in it.

Below desktop, is "Firefox" the systems web browser, that is not yet implemented, if a user clicks on it pop up a small window that says "Feature not implemented yet." with a "Ok" button that closes that window.

Under that, will be the 3 "programs" that are "installed" in the system, MSN Messenger, Mush Client, IRC Client. Each with the appropriate icon and functionality.
