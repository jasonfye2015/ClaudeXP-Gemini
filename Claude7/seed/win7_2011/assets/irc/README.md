# Supplied FurNet IRC assets

The network settings, regulars, and mIRC icon were supplied in
`IRC_1791835297161.zip`. The original JSON and icon are retained unchanged.
The network is simulated locally; `FurNet.IRC:6667` is a display identity,
not an external connection.

The simulator filters human characters to verified ages 21+. Zeph (17) and
Gill (20) remain in the source file but do not participate. Idle nicknames
without an adult profile are excluded until age information is supplied.
Explicit bots are service programs, not human character profiles.

The supplied server history and channel topics retain their original references
to 2001–2002. The application's clock and generated conversation remain in 2011.
