# Claude Timeline

Three computers from three moments in time, sharing one archive and one cast of characters:
EPOCH-2001 (Windows XP), SYSTEM-2011 (Windows 7) and WORKSTATION-2025 (Windows 11), recreated in Python and Qt.
Each one shows a personal furry media archive through tools that work the same in every era, with residents,
messengers, games and local AI models around it. [PLAN.md](PLAN.md) describes the whole project.

It's built to host one person's archive for themselves. The archive lives in `Local Storage`, which isn't part of
this repository, so without it much of the system has no content.
